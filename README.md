# Data-poison-attack-detection-and-mitigation-study
Data-poison-attack-detection-and-mitigation-study


Deep learning systems increasingly rely on continuous or incremental training, which exposes them to training-time data poisoning attacks that can silently alter model behavior. This proposes an online defense framework that detects and mitigates poisoned updates by monitoring training dynamics rather than relying only on final model inspection. The method tracks signals such as gradient magnitude, directional consistency, activation shifts, and loss smoothness, then applies cumulative sum change detection to identify sustained deviations from normal optimization behavior. When suspicious patterns are detected, the framework can skip, down-weight, or roll back affected updates to limit the influence of poisoned data without requiring clean reference datasets or expensive retraining. The approach is designed to work in both centralized and federated learning settings and is evaluated across several attack families, including classical backdoors, stealthy hidden-trigger attacks, availability poisoning, adaptive intermittent attacks, and multi-objective poisoning. By focusing on temporal training behavior, the framework aims to provide early, lightweight, and generalizable protection against a broad range of poisoning threats.
